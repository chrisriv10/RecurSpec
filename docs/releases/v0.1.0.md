# RecurSpec v0.1.0

First public release of RecurSpec.

RecurSpec tests whether recovery instructions printed by command-line tools actually work.

## Highlights

- Extract recovery commands from CLI output
- Follow multi-step recovery paths
- Retry the original command or verify the resulting state
- Detect ambiguous advice and recovery loops
- Block unsafe recovery commands
- Run each case in an isolated workspace
- Human, JSON, JUnit, and Markdown output
- `--dry-run` for inspecting a contract before execution

The test suite also includes cases from Git, Cargo, and npm.

## Install

```bash
pnpm add -D recurspec
```

```bash
pnpm exec recurspec init
pnpm exec recurspec validate
pnpm exec recurspec test
```

RecurSpec is early-stage software. The config format and public API may change before v1.0.
